# 빛결 | 항산화 시료 탐구 자료실

스마트폰 RGB 분석 기반 항산화 시료 비교 자료실입니다. HTML, CSS, JavaScript만 사용하는 정적 웹사이트이며 서버나 데이터베이스는 필요하지 않습니다.

## 파일 구성
- `index.html`: 메인 페이지와 5개 자료 섹션(실험 데이터, 변화율 분석, 시료 자료실, 분석 가이드, 연구 기록)
- `styles.css`: 보라색·초록색 중심의 반응형 디자인과 모바일 메뉴
- `data.js`: 실제 제공받은 최종 RGB 데이터, 최종 G 채널 상대 변화율, 시료 정보, 확인 가능한 참고문헌을 관리하는 단일 데이터 파일
- `app.js`: 데이터 표 필터, SVG 선그래프, 시료 상세 영역, 상대 변화율 계산기, 새 기록 CSV 다운로드 기능

## GitHub Pages 배포 (태블릿)
1. GitHub에서 새 **Public** 저장소를 만듭니다(예: `bitgyeol-antioxidant-archive`).
2. 저장소 최상위에 `index.html`, `styles.css`, `data.js`, `app.js`, `README.md`를 업로드합니다. ZIP 자체를 올리지 말고 압축을 풀어 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 설정하고 **Save**를 누릅니다.
6. Pages 설정 화면에 표시되는 공개 URL을 엽니다. 첫 배포에는 잠시 시간이 걸릴 수 있습니다.

## 데이터·해석 원칙
- RGB 측정값은 사용자가 제공한 최종 12개 데이터만 등록했습니다.
- 대조군 RGB `(244, 216, 234)`와 G 기준값 `216`, 아로니아+에탄올 블랭크 `(239, 218, 211)`는 별도로 표시합니다.
- G 채널 상대 변화율은 사용자가 제공한 최종 값으로 표와 그래프에 표시하며, `app.js`에서 RGB G값과 대조군 G값으로 다시 계산해 일치 여부를 검증합니다.
- 이 상대 변화율은 실제 DPPH 라디칼 소거율이나 항산화력 자체가 아닙니다.
- 확인되지 않은 시료 제품 함량이나 실험 조건은 생성하지 않습니다. 새 기록 양식은 브라우저에서 임시로 관리되며 CSV로 내려받을 수 있습니다.

## 참고문헌
웹사이트의 `data.js`에 제목, 저자/기관, 연도, 설명 및 링크를 기록했습니다. 외부 링크는 원문 또는 공식 자료로 연결됩니다.
